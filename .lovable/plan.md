## Goal
Wire up post-mux audio so silent video models (Kling 2.1 Master, etc.) can ship with Music / SFX / Ambient generated by ElevenLabs.

## Steps

1. **Request `ELEVENLABS_API_KEY`** via the secrets tool before any backend work.

2. **New edge function `mux-audio`** (`supabase/functions/mux-audio/index.ts`)
   - Input: `{ video_url, audio_plan: { mode: 'music'|'sfx'|'ambient', style?, duration_seconds }, panel_context: { director_note, scene_summary } }`
   - Auth: verify JWT, charge credits (small fixed cost, e.g. 2 credits) via `charge_credits`, refund on failure.
   - Build an audio prompt from `mode + style + panel_context` (Director-aware: scene mood, location, action).
   - Call ElevenLabs:
     - `music` → `POST /v1/music` with `prompt` + `duration_seconds`
     - `sfx` / `ambient` → `POST /v1/sound-generation` with `text` + `duration_seconds` (ambient uses a "continuous ambient bed" prompt prefix; sfx uses "discrete sound effects layer")
   - Upload returned MP3 to `generation-images` bucket (or new `director-audio` bucket — will create if missing) at `mux/{user}/{uuid}.mp3`, get signed URL.
   - Mux via `fal-ai/ffmpeg-api/compose` with two tracks (video + audio), trim audio to video duration, return final `video_url`.
   - Log to existing render record if `render_id` provided.

3. **Storage**: add `director-audio` bucket (private) via migration so muxed assets live separately from images.

4. **Wire `generate-video` to call `mux-audio`** when:
   - Selected model has `audio: false` in catalog, AND
   - `audioPlan.mode !== 'none'`
   
   After fal returns the silent video, await `mux-audio` and replace the returned URL with the muxed one. Surface a `mux_status` field on the result so the UI can show "Adding music…" → "Done".

5. **`AnimatePanelDialog` updates**
   - Remove the "swap to audio model" auto-suggest when user explicitly wants Kling 2.1 Master — instead show: "We'll add {music|sfx|ambient} after rendering (+2 credits)".
   - Show progress toast for the mux phase.

6. **Storyboard "Animate all panels" continuity**
   - Generate one shared `style_seed` (e.g. "warm orchestral, 90 BPM, cinematic strings") via Director agent once at the start of the batch.
   - Pass the same seed to every panel's `mux-audio` call so all 6 clips feel like one score.
   - Store on the storyboard render record.

## Files
- **New**: `supabase/functions/mux-audio/index.ts`
- **Edited**: `supabase/functions/generate-video/index.ts`, `src/components/director/AnimatePanelDialog.tsx`, `src/components/director/DirectorChat.tsx` (batch style seed)
- **Migration**: create `director-audio` storage bucket + RLS

## Verification
1. Animate panel #1 with Kling 2.1 Master + Music → silent fal output → ElevenLabs music generated → ffmpeg mux → final clip has audio matching scene mood.
2. Animate all 6 panels with Ambient → all share same ambient bed style.
3. Pick Veo 3.1 + Music → still uses native `generate_audio` (no post-mux), no double-charge.
4. ElevenLabs failure → video still returned silent, credits refunded for the mux step only, toast warns user.

## Out of scope
- Voiceover / dialogue
- User-adjustable mix levels (ducking, volume) — fixed defaults for now
- Per-panel audio crossfades between clips (storyboard-level concat is a separate feature)
